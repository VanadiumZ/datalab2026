# DataLab 解题思路

## bitAnd

用德摩根律：`x & y` 等价于 `~(~x | ~y)`。先把两个数取反，再做或运算，最后把结果取反，只用 `~` 和 `|`。

## bitXor

异或在两个对应位不同时为 1。`~(x & y)` 排除两个位都是 1 的情况，`~(~x & ~y)` 排除两个位都是 0 的情况。把这两个结果相与，留下的就是不同的位。

## samesign

算术右移 31 位可以取得符号：负数得到全 1，非负数得到 0。两个结果异或后取逻辑非，可以判断符号位是否相同。

题目把 0 单独看作一类，所以还要比较 `!x` 和 `!y`。只有符号位相同，并且两者同时为 0 或同时不为 0，才返回 1。

## logtwo

结果是最高有效位的位置，也就是以 2 为底的对数向下取整。

先判断数是否大于 `0xFFFF`。如果是，说明最高位在高 16 位，把数右移 16 位，并在结果中记下 16。再按 8、4、2 位重复这个过程。最后剩下的数右移 1 位，得到最后一位的位置增量。

每次记录的增量分别占结果的不同位，因此可以用或运算合并，不需要加法或分支。

## byteSwap

字节编号乘 8 就是它的位偏移，用左移 3 位计算。把两个目标字节分别右移到最低位，异或后用 `0xFF` 截取，得到它们不同的位 `diff`。

把 `diff` 移回两个目标位置，再分别与原数异或，就能交换这两个字节。相同的位不变，不同的位翻转，其他字节也不受影响。两个字节编号相同时，`diff` 为 0，结果自然不变。

这里的 `0xFFu` 让移回字节的左移在无符号表达式中进行，避免移到最高位时发生有符号左移溢出；局部变量仍然都是 `int`。

## reverse

循环 32 次，每次取出 `v` 的最低位，接到结果的末尾，然后将 `v` 右移一位。

先取出的低位会随着后续循环不断左移，最后到达高位，所以整个 32 位数的顺序被反转。输入和结果都是无符号数，右移时高位补 0。

## logicalShift

先对 `x` 做算术右移，再用掩码清除高位补出来的 1。

当 `n > 0` 时，所需掩码是低 `32 - n` 位为 1，可以用 `0x7FFFFFFF >> (n - 1)` 得到。不能在 `n = 0` 时右移负数位，所以令 `zero = !n`，把移位量写成 `n - 1 + zero`，代码中用 `~0` 表示 -1。

`~zero + 1` 在 `n = 0` 时为全 1，其他时候为 0。把它并入掩码，就能在不使用分支的情况下处理不移位的情况。

## leftBitCount

若最高位是 0，答案一定是 0。若最高位是 1，对原数取反后，问题就变成统计开头有多少个 0。

令 `v = ~x & 0x7FFFFFFF`，清除最高位，使后续处理都在非负数上进行。用 16、8、4、2、1 位逐步缩小范围，找到 `v` 的最高有效位位置 `result`。这里用 `!!(v >> k)` 判断高位部分是否非零。

当 `v` 非零时，原数开头连续 1 的数量就是 `31 - result`。当 `v` 为 0 且原数为负时，原数是全 1，答案应为 32，所以额外加上最开始保存的 `!v`。

最后与 `x >> 31` 相与：负数保留计算结果，非负数得到 0。

## float_i2f

单精度浮点数由 1 位符号、8 位阶码和 23 位小数组成。先保存符号，再用无符号数保存绝对值。负数通过取反加一得到绝对值，这样也能表示最小负整数的绝对值。

0 单独返回。其他数不断左移，直到最高的 1 到达第 31 位。阶码初值是 `127 + 31 = 158`，每左移一次减一，最终得到实际最高位位置加上偏置 127。

移位后的数右移 8 位，去掉隐藏的最高位 1，便得到 23 位小数。低 8 位是需要舍弃的部分，用来决定舍入：

- 大于 `0x80`，向上舍入。
- 小于 `0x80`，保持不变。
- 等于 `0x80`，恰好在中间，仅当保留部分的最低位为 1 时加一，使结果取偶数。

小数舍入可能产生进位，所以用加法连接阶码和小数，让进位自然进入阶码，最后并入符号位。

## floatScale2

先拆出符号、阶码和小数，再按浮点数的类别处理：

- 阶码全 1：无穷大和 NaN 直接返回原位模式。
- 阶码为 0：把小数左移一位，表示乘 2。若产生进入阶码的进位，也正好完成从非规格化数到规格化数的转换。
- 其他情况：阶码加一，小数保持不变。

如果阶码加一后变成全 1，就返回带原符号的无穷大，小数清零。

## float64_f2i

从高 32 位 `uf2` 中提取符号和阶码，阶码减去偏置 1023，得到实际指数。把高位小数与隐藏的 1 合并，得到有效数字的高 21 位。

实际指数小于 0 时，绝对值不足 1，向零取整得到 0。实际指数大于 30 时，返回题目规定的 `0x80000000`。其中合法的 `-2^31` 恰好也用这个位模式表示，因此可以合并处理。

指数不超过 20 时，只需右移高 21 位。指数在 21 到 30 之间时，先左移这部分，再从 `uf1` 中取出缺少的低位并入。移位直接舍弃小数部分，实现向零取整。

最后根据符号决定是否取负。

## floatPower2

`2^x` 的位模式按指数范围直接构造：

- `x < -149`：小于最小非规格化数，返回 0。
- `-149 <= x < -126`：使用非规格化表示，小数字段的第 `x + 149` 位为 1。
- `-126 <= x <= 127`：使用规格化表示，阶码为 `x + 127`，小数字段为 0。
- `x > 127`：超出表示范围，返回正无穷大 `0x7F800000`。
